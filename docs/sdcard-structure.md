# EdgeTX SD Card Structure

Copy the contents of `dist/SDCARD` to the root of the TX15 SD card.

Expected layout:

```text
SDCARD/
  WIDGETS/
    SoarF5J/
      main.lua
      lib/
      competition/
      setup/
      pages/
```

In EdgeTX, add a SoarF5J widget to a model screen and select the required page in widget options.
